5 · Карточки заметок ИИ (ai_notes) — 3 типа, разные цвета

Где: блок «Заметки ИИ» в детали. Что: ai_notes[{date,type,text}] как лента. type красит карточку.
accelerate · risk · info
Ускорить · accelerate9 июн

Этап «Поиск» закрыт раньше срока. Шанс поднят до 72%. Критический путь — юр.проверка.
type → цвет: accelerate = ember (как ускорить) · risk = красный (что угрожает) · info = синий (контекст/обновление). Каждая с датой. Лента сверху-вниз, свежее выше.
ZERO-AFK: заметки ИИ не генерятся в приложении. Их пишет интерактивный Claude в чате (разбор статуса ~раз в петлю) через write-API; экран только отображает накопленный массив ai_notes. Нет кнопки «обновить AI» с live-вызовом модели — обновление инициирует владелец в чате командой «обсуди проект».

7 · Тап «+ Новый проект» → разобрать с ассистентом (ZERO-AFK)

Где: кнопка внизу пульса. Что: НЕ форма с «AI рассчитай», а отправка в чат-разбор.
тап «+ Новый проект»
Новый проект
Большую цель мы разбираем в чате: вместе зададим срок, этапы и оценим шанс. Карточка появится заполненной.
Черновик вручнуюОткрыть чат
Два пути: «Открыть чат» = разбор с Claude (рекомендуемый, заполнит вероятность/срок/этапы/заметки). «Черновик вручную» = пустая карточка-болванка, поля заполнишь сам, AI-блоки пустые до разбора. Цель года/квартала из .life → сюда как проект.
ZERO-AFK: создание проекта не дёргает LLM из приложения. «Разобрать с ИИ» = открыть диалог с интерактивным Claude (в Telegram/чате), который через write-API запишет success_probability, target_date, этапы и первые ai_notes. Приложение — только трекинг и отображение.

8 · Деструктив: удалить / архивировать проект

Где: ⋯ в навигации детали → меню. Что: архив (мягко) / удалить (с подтверждением).
подтверждение удаления
Удалить «Продать студию ZIMA»?
Проект, все этапы, привязка задач и заметки ИИ удалятся навсегда. Задачи останутся, но потеряют этап. Отменить нельзя.
ОтменаУдалить
Сначала предлагаем «Архивировать» (проект прячется из пульса, история и заметки сохраняются, можно вернуть). Удалить — безвозвратно, с честным текстом про потерю привязок. Задачи не удаляются вместе с проектом, только теряют stage_id. Деструктив всегда с подтверждением (правило проекта).
