Быстрая задача — ЕДИНСТВЕННОЕ поле создания (на «+»)

+ → это поле. Второго поля/полного composer НЕТ. Открывается без клавиатуры (фокус не на инпуте) — тапаешь поле/чипы сам.
Q1 дата → пикер «Дата/время» (см. T1-datetime): старт+дедлайн, календарь с heat, длительность. Инлайн поверх поля.
Q2 проект → список проектов (выбор/создание).
Q3 приоритет → P1/P2/P3/нет. Q4 тег → выбор/создание тегов.
Q5 напоминание → тот же пикер «Дата/время» (напоминание живёт там).
Чип «on» (ember) когда значение задано — показывает выбранное (дата/проект/P#/#N).
NL: набрал «завтра !1 #тег ~ZIMA» → токены подсвечены, чипы загораются авто; тап токена → назад в текст.
