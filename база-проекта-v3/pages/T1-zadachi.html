Контракт (решения 11.06):
• ☰ Бургер (T1-A) — слева от «Задачи». Только ОТКРЫВАЕТ шторку; сама шторка = отдельный контракт F17 (features/F17-drawer.html): аватар+корона, смарт-списки, проекты-emoji, свайп Изменить/Удалить, свободный цвет. Выбор = переход на экран Списка. Edge-свайп тоже открывает. NB: прод-ProjectTreePanel пока старее F17 — апгрейд до F17 = свой таск, не Форк A.
• Чип справа от даты — две роли: на ДРУГОМ дне = «Сегодня» (прыжок на сегодня); на сегодня = «Сейчас» (скролл к now-линии).
• Свайп ◀▶ по таймлайну = пред/след день (и со старта на блоке, если не взведён перенос; левый край ≤24px отдан шторке). Хинт-пилюля исчезает после первого свайпа.
• Дата-кнопка (T1-D) = мини-календарь с тепло-заливкой по нагрузке дня (зелёный=лёгкий · жёлтый=средний · красный=забит/висят пропущенные важные · пусто=без цвета); today=ember-кольцо поверх; тап дня = сразу прыжок, «Сегодня» = быстрый возврат.
• All-day 3+ = показываем 2 чипа + «+N ещё» (тап раскрывает).
• FAB «Список» + [+] — пилюля «Список» видна только когда день = сегодня; на других днях только [+].
• Метка этапа = мишень + «этап N», цвет по статусу (current=ember · late=danger «!» · future=steel); не тапается; узкий блок = только иконка.
• Токен «вклад в успех» NN% = моно-пилюля в мете (bone/slate, НЕ цвет-сигнал), рядом с этапом через «·». Виден только при impact ≥ 30 И привязке к проекту/цели; быт/инбокс/без проекта — без токена. Пишет Claude в чате (ZERO-AFK), не приложение.
• Создание в ячейке на не-сегодня пишет задачу на выбранный день (due_date=выбранная дата). Смена дня = мгновенный свап без скелетона, гонка запросов отменяется (последний выигрывает).
Не тронуто: таймлайн, инлайн-создание, наложения=колонки, жесты переноса/ресайза.

Цвет=смысл. Фон=проект: ZIMA Здоровье planner Финансы. Полоса=приоритет: high med low.
