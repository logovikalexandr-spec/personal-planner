INBOX «Входящие» — функциональные флоу

Каждое касание карточки-идеи. Зелёное = рекомендация (куда улетает идея), красное = деструктив. ⚡ = SVG-молния, не emoji. Подсказку проект+этап даёт дешёвая эвристика (keyword→проект) ИЛИ Claude в чате — в UI НЕТ live-LLM-вызова. Это контракт Фазы 2.

2 · Тап «Принять» → идея становится задачей в проекте/этапе

Где: кнопка «Принять» в блоке-подсказке. Что: idea списывается из Inbox (status разобрано), InboxItem.raw_content → новая Task с stage_id = suggested_stage_id. Хаптик, тост с «Отменить».

Где: чип «в проект ▾» (на любой карточке). Что: снизу выезжает шит. Если есть подсказка — её строка преднажата (⚡-метка); если нет — выбор с нуля.

6 · Свайп влево по строке → действия прямо в строке

Где: смах карточки влево. Что: открываются 3 действия: в проект (зелёный) · на сегодня (ember) · удалить (красный). Те же, что чипы — быстрее для серийной разборки.

Свайп = серийный режим: разбираешь стопку, не раскрывая чипы. «Сегодня» и «Удалить» срабатывают сразу; «Проект» открывает шит (см. 4). Полный свайп до края = действие по умолчанию (на сегодня). Удаление через свайп — с подтверждением (см. 7).

7 · Удаление идеи → подтверждение (деструктив)

Где: чип/свайп «удалить». Что: нативный tg.showConfirm. Идея не раскладывается — стирается.
диалог подтверждения
Удалить идею?
«Купить подарок маме» удалится из Входящих навсегда. В проект или задачу не попадёт.
ОтменаУдалить
Удалить = идея исчезает, никуда не раскладываясь — поэтому с подтверждением (правило проекта: деструктив подтверждаем). Альтернатива «отложить»: не удалять, а просто оставить в Inbox — он не давит на цифрах. Без корзины: удалённую идею не вернуть (в отличие от «Принять» с «Отменить»).

8 · После разбора → тост «Отменить» (мягкий откат)

Где: после «Принять» / «на сегодня» / «в проект». Что: тост 5 сек внизу — если эвристика/выбор промахнулись, вернуть идею в Inbox одним тапом.
тост после «Принять»
В проект ZIMA · этап 4 Отменить
Сеть безопасности для ZERO-AFK-эвристики: подсказку дала не-LLM-логика — она может ошибиться. Тост 5 сек ловит промах без диалога. «Отменить» возвращает идею в Inbox с прежней подсказкой. После таймаута — разбор финален (но задачу всё ещё можно перенести в её проекте).

Что: разобрал/удалил последнюю карточку — экран не должен стать «пустой ошибкой», а спокойно показать «всё чисто».
