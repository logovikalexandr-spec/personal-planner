Заметки. Поля «Этап проекта» нет, если у задачи нет project_id — этап существует только внутри проекта. Ошибка загрузки детали наследует общий паттерн из T1-состояния (иконка-треугольник + «Не удалось загрузить» + «Повторить») — не дублируется здесь. Шит-загрузка не нужна отдельно: список этапов проекта уже в памяти при открытии детали; если проект пуст — сразу пусто-состояние (показано выше).
