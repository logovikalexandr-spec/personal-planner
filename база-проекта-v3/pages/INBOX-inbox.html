Наполнение «Входящие»

Inbox = статус захвата (GTD), не таб. Открывается из шторки или из «Задач», поверх — оверлей. Кнопка ‹ Назад возвращает откуда пришёл.
Быстрая обработка свайпом: смахнул карточку → в проект / на сегодня / дата / удалить. Те же действия дублируются чипами под текстом.
AI-предложение проекта (suggested) — агент читает мысль и подсказывает проект+этап (⚡ ember). Тап «Принять» — мысль улетает на место.
Захват отовсюду (FAB / quick-add / из сессий) падает сюда. Источник виден в каждой карточке.
Цель — ничего не теряется и не висит вечно: каждую пойманную мысль либо раскладываешь, либо удаляешь.
