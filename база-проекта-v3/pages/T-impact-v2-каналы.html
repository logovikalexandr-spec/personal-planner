Вклад в успех — БЕЗ конфликта с цветами строки

Строка уже кодирует: кант=приоритет, фон=проект, мишень=этап. Третий цвет не лезет. Решение: вклад = ТЕКСТ-число + сортировка + отдельный вид. Цвет не трогаем.

кант слева → приоритет (срочность-ручная: high/med/low) — БЕЗ изменений
фон → проект — БЕЗ изменений
мишень «этап N» → статус этапа — БЕЗ изменений
вклад% (новое) → МОНО-число в мете (не цвет) + драйвит сортировку «Фокус» + ось матрицы. Пишет Claude в чате.
Путь 1 · рекомендую
Мини-токен «↑80» в мете
Вклад — маленькое моно-число в строке меты, рядом с этапом. Текст, не цвет → ничего не конфликтует. Показываем только у заметных (≥порога), у фона скрыт.

+ Ноль конфликта цветов, число видно где важно. «↑» = направление к цели. У фоновых скрыт — список не пухнет.
Путь 2
Кант = важность от AI
Переосмыслить: ручной приоритет !1–3 → заменяет AI-важность (из вклада%). Кант УЖЕ это и есть «важность». Срочность = дедлайн. Матрица Эйзенхауэра выходит из существующих каналов, 0 нового на строке.

Толстый кант ember = высокая важность (AI). Тонкий серый = фон. Красная мета = горит срок.
+ Вообще ничего нового на строке. − Теряешь ручной !1–3 (или оставляешь оба: ручной перебивает AI).
Путь 3 · дом для числа
Только «Фокус» + Матрица
Строка-таймлайн вообще НЕ меняется. Вклад% живёт только в отдельном виде «Фокус» (сортировка) + в детали задачи + опц. матрице. Чисто, но не видно при беглом взгляде на день.
