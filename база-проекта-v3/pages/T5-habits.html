«Привычки» v3 — чистое наполнение

1 карточка = 1 прогресс + 1 действие. Слева кольцо-стрик (C2, путь к рубежу), справа галка ИЛИ «+» для числовой. Ряды-точки убраны — историю несёт heatmap.
Сводка дня сверху: «3 из 5 сегодня» — главный фокус экрана.
Чип расписания только у не-ежедневных (4×/нед, норма 2 л). Ежедневная = без чипа.
Мини-прогресс в строке — только где это суть (число/цель-дата), не у всех.
Heatmap = история (7/30д). Метрики = превью 2 карточки, полный список в суб-табе. Ретро = свёртка.
Меньше элементов, каждый со смыслом. Тап карточки → деталь привычки (стрик-календарь, правка, архив).

Функциональные флоу — все взаимодействия экрана

Каждое касание и состояние. Зелёное = поведение по умолчанию, красное = деструктив. Контракт Фазы 2.
