# Спека: Визуал-верификатор планнера (через chrome-devtools)

> ⛔ **УСТАРЕЛО (2026-06-14, профи-аудит).** Заменено: [конвейер v2 — Playwright](2026-06-14-конвейер-v2-playwright-design.md). Визуал теперь = Playwright `toHaveScreenshot` против human-baseline (не пиксель-диф мокап↔рендер, не MCP). Файл = история.

> Дата: 2026-06-13. Проект: personal-planner / planner-v2.
> Проблема: «макеты сделаны, промпт есть, а код пишется неточно» — дрейф мокап↔деплой.
> Корень (из TEAM.md §3): визуал-гейт есть, но он полу-ручной и **Claude судит сам себя** — reviewer ревьюит КОД (текст), а не РЕНДЕР (пиксели); chrome-devtools-браузер не вшит в шаг проверки.
> Решение: автоматический визуал-верификатор, который рендерит экран в реальном браузере, снимает скрин, **программно** сверяет токены с DESIGN.md и структуру с мокапом, выносит PASS/BLOCK.

## Контекст системы (слои)

Спека — часть большего апгрейда личной AI OS Александра. chrome-devtools используется в двух треках:

```
                  chrome-devtools (браузер-движок)
                 /                              \
   ТРЕК B (эта спека)                     ТРЕК 2 (отдельно)
   ТВОИ приложения                        ЧУЖИЕ AI-сайты (консилиум)
   localhost / планнер-прод               ChatGPT / Gemini web
   свободный заход (твоё, ToS ок)         ⚠️ хук спрашивает ПЕРЕД заходом
```

Эта спека покрывает **ТРЕК B**. Трек 2 (консилиум через браузер + жёсткий PreToolUse-хук на заход) — в разделе «Следующие шаги».

## ТРЕК B — Визуал-верификатор

### Цель

Экран не «готов», пока его **рендер в браузере** не совпал с мокапом по токенам, структуре и состояниям. Гейт **обязательный** и **программный**, а не «глаз в Telegram».

### Архитектура

Новый агент **`visual-verifier`** в `planner-v2/.claude/agents/visual-verifier.md`. Запускается как шаг **Фазы-3 (Гейт)** ПЕРЕД вердиктом `reviewer`. Не строит код — только судит. Возвращает структурированный вердикт.

### Поток (на один экран, напр. T2 Календарь)

```
1. РЕНДЕР LIVE
   - cd planner-v2/frontend && npm run dev (vite на :5173)
   - chrome-devtools navigate → http://localhost:5173/app/preview-<screen>-mock.html
   - resize_page → 390×844 (Telegram моб.)
   - take_screenshot → live.png

2. РЕНДЕР ЭТАЛОН (мокап)
   - chrome-devtools navigate → file://.../база-проекта-v3/pages/<TX>.html
   - resize_page → 390×844 (тот же вьюпорт)
   - take_screenshot → mock.png

3. СВЕРКА ТОКЕНОВ (программно — главное)
   - evaluate_script на live: для ключевых элементов getComputedStyle →
     { color, backgroundColor, fontFamily, fontSize, fontWeight, padding, margin, gap, borderRadius }
   - сверка с DESIGN.md:
       • акцент только #EE8A3C (ember); фон #0F0F11 (onyx, НЕ #000)
       • шрифт Geist / Geist Mono (НЕ Inter/serif/system)
       • отступы кратны 4
       • приоритеты: high #FF5C5C, medium #FFB02E
       • НЕТ emoji в хроме (только иконка проекта)
   - каждое несоответствие → запись в diff

4. СВЕРКА СТРУКТУРЫ И СОСТОЯНИЙ
   - side-by-side live.png + mock.png
   - проверка: порядок блоков, наличие состояний empty/loading/error
     (мокап их показывает — live обязан тоже)

5. ВЕРДИКТ
   - PASS: diff пуст → reviewer может MERGE
   - BLOCK: diff не пуст → список { элемент, свойство, ждали, получили } →
     назад в frontend-агента → фикс → повтор с шага 1, пока PASS
```

### Контракт вердикта (frontmatter + тело)

```yaml
screen: T2-calendar-week
status: pass | block
checked_at: 2026-06-13
tokens:
  - element: ".task-row .priority-edge"
    property: background-color
    expected: "#FF5C5C"
    actual: "#EE8A3C"
    verdict: fail
structure:
  - check: "состояние empty присутствует"
    verdict: pass
  - check: "порядок: заголовок → дни-полоса → таймлайн"
    verdict: pass
screenshots:
  live: "frontend/design/verify/T2-live.png"
  mock: "база-проекта-v3/pages/T2a-calendar-week.html"
blockers:
  - "priority-edge использует ember вместо signal-red — приоритет high не читается"
```

### Что нужно для сборки

- **preview-файлы** для каждого экрана (часть уже есть: `preview-t1-mock.tsx`, `preview-tracking-mock.tsx`, `preview-today-mock.tsx`). Дособрать недостающие (T2/T3/T4/DETAIL/INBOX) с mock-данными, совпадающими с мокапом.
- **Промпт агента** `visual-verifier.md`: роль (независимый судья), вход (имя экрана + путь мокапа), инструмент (chrome-devtools), выход (контракт вердикта), правило «не чинит — только судит и блокирует».
- **Вшивка в TEAM.md**: Фаза-3 шаг 0 = visual-verifier ПЕРЕД reviewer. reviewer не выносит MERGE, пока visual-verifier не PASS.
- **Папка скринов**: `frontend/design/verify/`.

### Почему это сильнее текущего

| Было | Стало |
|---|---|
| reviewer читает код (текст) | verifier рендерит и снимает пиксели |
| «глаз в Telegram», поздно, в проде | браузер локально, ДО merge |
| токены сверялись на глаз | токены сверяются программно (getComputedStyle vs DESIGN.md) |
| гейт опциональный | гейт обязательный, BLOCK блокирует deploy |

### Известное ограничение (принято владельцем)

visual-verifier — это всё ещё Claude, рендерящий свой же код. Та же слепая зона теоретически возможна (может «простить» себе расхождение). Митигация на старте: сверка **программная** (числа не врут, в отличие от «похоже»). Если дрейф останется — добавить независимый глаз: скрин → vision-AI (GPT/Gemini) как судья (см. Трек 2).

## Следующие шаги (Трек 2 — отдельная спека)

### Консилиум / второе мнение через браузер

```
триггер: "спроси GPT" / "созови консилиум" / независимая верификация
   ↓
⚠️ ЖЁСТКИЙ ГЕЙТ (PreToolUse-хук на chrome-devtools navigate):
   домен openai.com / chatgpt.com / gemini.google.com → форсит разрешение
   "зайти на [сайт], отправить [запрос]? да/нет"
   свой домен (localhost / планнер-прод) → свободно
   ↓ да
chrome-devtools → логин-сессия → печатает промпт → ждёт → скрапит ответ → Claude
```

**Гейт = жёсткий хук** (выбор владельца), domain-aware. Реализация: `~/.claude/hooks/external-ai-gate.sh`, PreToolUse на `mcp__chrome-devtools__navigate_page`, проверка URL → permissionDecision "ask" для внешних AI-доменов.

**Принятый риск:** автоматизация веб-UI ChatGPT/Gemini против их ToS (риск бана аккаунта) + хрупкость (DOM/капча). Митигация: человек-в-петле перед каждым заходом. Легальная альтернатива для Gemini — бесплатный API-tier (без браузера); для ChatGPT free API нет.
