## Что изменилось против v1 (и почему)

| v1 (homegrown) | Вердикт | v2 (профи) |
|---|---|---|
| токены: рендер → `getComputedStyle` → сверка | детект-постфактум, слабая версия | **предотвращение**: `theme.css` (CSS vars, уже есть) + **stylelint бан сырого hex** → дрейф цвета/шрифта структурно невозможен в коде |
| контракт = инертный YAML (`behaviors:`/`flows:`) | анти-паттерн (ничего не запускает) | контракт = **Playwright-тесты** с заголовками-критериями приёмки. Тест сам и есть контракт |
| chrome-devtools MCP как гейт | анти-паттерн (LLM-в-петле каждый прогон, недетерминизм) | **Playwright** (детерминизм, headless, free, WebKit=Telegram iOS). MCP только чтобы *написать* тест 1 раз |
| скрин live vs скрин мокапа (пиксель-диф) | анти-паттерн (кросс-пайплайн: шрифты/AA/субпиксели → ложь) | `toHaveScreenshot` против **своего baseline, утв. человеком 1 раз**. Мокап = только человеческий референс |
| bash+grep: ecode → строка YAML | идея RTM здравая, цель неверна | греп: ecode → **есть Playwright-тест** (по `data-testid`). Гейт доказывает «тест есть», CI — «тест зелёный» |
| `check-coverage.sh` грепает `data-ecode=` | **мёртв**: разметка = `<span class="ecode">A1</span>` (код=текст, суффиксы `·T1`/`·DETAIL`) | греп текста `.ecode`, отрезать суффикс по `·` |
| preview-*.tsx руками | оставить (не Storybook, 0 deps, ОК для соло) | оставить, навести Playwright на preview-файлы |

**Сквозной принцип:** перейти от «детект после того как AI отрендерил/осудил» к «предотврати в источнике + сверь против фиксированного человеком артефакта».

## Слепая зона «Claude судит свой код» (подтверждена)

NeurIPS 2024 (Panickssery et al.): LLM-судья системно favorит свою генерацию; **брат-агент на той же модели НЕ независим** (общий отпечаток → скоррелированные слепые зоны). Лечение — не «второй агент», а:
1. **Детерминированные ассерты** (точные значения, не «похоже»).
2. **Baseline утверждает человек 1 раз** → машина вечно держит `new == approved`. AI не может переутвердить.
3. **Железно: AI НИКОГДА не запускает обновление baseline** (`playwright --update-snapshots`, `-u`). Иначе «snapshot fatigue»: агенту сказали «сделай тесты зелёными» → он перезаписал эталон и тихо благословил баг. Команды обновления — вне permission-листа агента.
4. Нужен реальный суд → модель **другого семейства** (GPT/Gemini), не брат.

## Слой 0 — ПРЕДОТВРАЩЕНИЕ (фундамент, новое)

Цель: дрейф цвета/шрифта/отступа невозможен в коде, ловится на строке (мс, без браузера).

- `src/theme.css` — токены как CSS-переменные. **Уже есть:** `--bg #0F0F11`, `--surface`, `--accent #ee8a3c`, `--danger #ff5c5c`, `--warning #ffb02e`, `--text`, `--border`, `--radius`, `--font`, `--font-mono`.
- **Проблема найдена:** сырой hex в 8 файлах вне theme.css, включая дубли токенов (`#ee8a3c`, `#ff5c5c`, `#ffb02e` хардкодом вместо `var()`) + палитра проектов (`#3FB68B`, `#5B8DEF`, `#9B6BE0` — это data-цвета, легитимны, в allowlist).
- **stylelint** + `stylelint-declaration-strict-value` (`color`/`background-color`/`fill`/`border-color` → обязан `var()`), `color-no-hex` как бэкстоп. Исключения: `theme.css` (определения) + палитра проектов (вынести в `--project-*` токены или allowlist).
- **ESLint** `no-restricted-syntax` — бан hex-литералов в `.tsx` (inline-стили).
- Отступ-не-×4 — правило в том же stylelint.

Эффект: после этого слоя `getComputedStyle`-сверка для токен-свойств **избыточна**. Остаётся тонкий смоук токен-резолва (Telegram `--tg-theme-*` / каскад).

## Слой 1 — КОНТРАКТ = Playwright-тесты

Контракт экрана = НЕ YAML. Это файл `tests/<screen>.spec.ts`, где:
- каждый `test("...")` заголовок = критерий приёмки на языке пользователя («задача прилипает к 15-мин сетке»);
- behaviors → `test()` с `click`/`dragTo`/`fill`;
- flows + persist → действие → `page.reload()` → ассерт что состояние выжило;
- visual → `toHaveScreenshot()` против baseline;
- токен-смоук → `toHaveCSS()`.

Покрытие: `coverage.sh` грепает `.ecode` из мокапа (текст, отрезая `·суффикс`) → для каждого кода ищет `data-testid` или маркер в spec-файле. PASS = каждый интерактивный элемент мокапа имеет тест. CI = тесты зелёные.

Владелец сверяет **один раз** при заведении экрана: список заголовков тестов + FLAG-вопросы («это всё, что я хотел?»). Это единственная ручная сверка линейки.

## Гейты (в терминах Playwright)

| Граница | Что проверяет | Как (Playwright) | Статус |
|---|---|---|---|
| идея → мокап | мокап покрыл всё | product-depth+designer, владелец утвердил | ✅ есть |
| **код → токены** | нет сырого hex/off-grid | **stylelint/eslint** (НЕ браузер) | 🔨 слой 0 |
| мокап → контракт | каждый ecode → тест | `coverage.sh` (греп исправлен) | 🔨 |
| логика | unit зелёный | vitest (есть) | ✅ |
| рендер == дизайн | визуал не уехал | `toHaveScreenshot` vs human-baseline | 🔨 |
| токен-резолв | vars резолвятся в Telegram | `toHaveCSS` (тонкий смоук) | 🔨 |
| поведение e2e | фичи+flows+persist работают | `click`/`dragTo`/`reload`+ассерт | 🔨 |
| прод == верифиц. | то же на проде | тот же сьют против прод-URL | 🔨 |

Один инструмент (Playwright) закрывает визуал+поведение+деплой. reviewer не MERGE пока сьют не зелёный.

## Стек (free/OSS, под React 18 + Vite 5 + Telegram)

```
ПРЕДОТВРАЩЕНИЕ:  theme.css (есть) + stylelint(strict-value+color-no-hex) + eslint(no hex literal)
ПРОВЕРКА:        @playwright/test — toHaveScreenshot + toHaveCSS + click/dragTo/reload
                 против preview-файлов локально И против прод-URL (=деплой-гейт, тот же сьют)
ИЗОЛЯЦИЯ:        preview-*.tsx (есть паттерн: entry .html + .tsx, мок window.fetch, theme.css)
ЧЕСТНОСТЬ:       baseline в репо, AI без права --update-snapshots; суд-резерв = чужая модель
```

Почему Playwright, не Cypress: WebKit (Telegram iOS webview), `dragTo` под @dnd-kit, trace viewer, free. Telegram: застабить `window.Telegram.WebApp`/`initData` чтобы гейт не зависел от живого клиента.

**Выкинуть:** пиксель-диф мокап↔рендер, MCP-как-гейт, getComputedStyle-как-главную-защиту, инертный YAML, брата-судью, Storybook (тяжёл для соло), Style Dictionary (оверкилл на 1 акцент).

## Порядок внедрения

1. **Слой 0 предотвращение** — stylelint/eslint бан hex + дочистить сырой hex → var(). Дёшево, убирает источник дрейфа. **Первым.**
2. **Playwright скелет** — поставить, конфиг (390×844, WebKit+Chromium), застабить Telegram.
3. **Гейт 1 на T2** (золотой пример): preview-t2 + `tests/T2.spec.ts` (behaviors/flows/persist) + baseline (владелец утв.) + `coverage.sh` (греп исправлен) + вшивка в TEAM.md.
4. Остальные экраны (T1/T3/T4/T5/DETAIL/INBOX) — по мере сборки.
5. Деплой-гейт — тот же сьют против прод-URL.
6. Резерв: чужая модель-судья, если самопроверки мало.

Каждый шаг = своя фаза. План шага 1+3 — `контекст/планы/2026-06-14-gate1-playwright-v2.md`.
