## Принципы наполнения (v3)
- **1 карточка = 1 прогресс-индикатор + 1 действие.** Ряды-точек убраны (историю несёт heatmap).
- Карточка: кольцо-стрик слева · имя + 1 строка · справа галка (бинар) ИЛИ «+» (число).
- Чип расписания — только у не-ежедневных. Мини-прогресс в строке — только где суть (число/цель-дата).
- **Сводка дня** сверху: «3 из 5 сегодня · 60%».
- **Без emoji** (DESIGN §8): флейм/ретро/галка = SVG.

## Взаимодействия (из T5-flows.html)
1. «+» привычка → шит-конструктор (имя·тип·расписание·цвет; поля по типу).
2. Тап карточки → **деталь** (большое кольцо · стрик/рекорд/% · месяц-календарь · Изменить/Архив/Удалить).
3. Тап галки → toggle (+1/цвет/кольцо), **обратимо, без подтверждения**.
4. «+» числовой → степпер (−/+ · пресеты · сохранить).
5. Долгий тап / свайп влево → меню (Изменить/Переместить/Архив/Удалить). **3 пути к удалению.**
6. Удалить → **confirm** (история теряется, деструктив). Архив = мягкий, обратимый, предлагаем первым.
7. «+» метрика → шит (имя·единица·направление «хорошо» ↓/↑·цвет).
8. Тап метрики → деталь (график · период 7/30/год · лог · «+ замер»).
9. Тап ячейки heatmap → **бэкфилл** прошлого дня (будущее недоступно; только тут и в деталь-календаре).
10. Пустые: 0 привычек/0 метрик → CTA. Heatmap скрыт при 0.
11. Edge: стрик прерван (0, рекорд хранится) · цель-дата достигнута (продлить/завершить).

## Модель данных (новая, для миграции Фазы 2)
```
Habit{ id, name, color, kind(binary|quantity), schedule(daily|x_per_week|days_of_week|goal_date),
       target_per_week|null, unit|null, norm|null, goal_total|null, goal_date|null,
       area|null, archived, order, created_at }
HabitLog{ id, habit_id(FK), date, value(bool|number), UNIQUE(habit_id,date) }
Metric{ id, name, unit, good_dir(up|down), color, archived, order }
MetricEntry{ id, metric_id(FK), date, value, UNIQUE(metric_id,date) }

```
