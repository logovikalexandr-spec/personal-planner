## ПРИНЦИПЫ РАБОТЫ (процесс, через который гоним)

1. **Воронка чтения.** CLAUDE.md → `инструкции.md` → нужный файл (lazy). Реестр мокапов — по ссылке `V2/V3 P.. A..`.
2. **Фазы.** Фаза 1 = **мокап-first**: открыть мокап через `open`, пройтись по визуалу+флоу вместе, править сам HTML-мокап, ждать **«утверждаю»**. Код приложения НЕ писать до утверждения. Фаза 2 = сборка по утверждённому мокапу. Фаза 3 = depth-гейт.
3. **Мокап = контракт.** Визуал-диф (открыть, сравнить) перед merge. Гейты: depth-first (матрица состояний пусто/загрузка/ошибка/edge, не happy-path), pytest/vitest зелёные, подтверждение владельца на проде.
4. **Адресация V2↔V3.** Формат `<версия> <страница> <фрейм><элемент>` — напр. `V3 T1 A4`, `V2 F17 C2`. Бейджи (`fcode`/`ecode`) вшиты в мокапы. Источник истины — `контекст/реестр-мокапов.md`. Кросс-рефы прямо в бейдже: `A1·F17` (бургер→шторка), `·DETAIL`, `·T1`.
5. **Протокол «записал».** Содержательное решение → пишу в реестр + правлю мокап + отвечаю строкой `✓ записал <код> → …`. Нет строки «записал» = НЕ зафиксировано, переспроси.
6. **ZERO-AFK (жёсткий закон).** Приложение/бэк НЕ зовёт LLM. Весь AI = интерактивный Claude, пишет в БД через write-API. 0 LLM в проде → 0 платы. С 15.06 Anthropic делит биллинг.
7. **Варианты — на мокапах** (`open` в браузере), не словами. Бесплатный/OSS стек. БЕЗ emoji в UI. Язык — русский, код — английский.
