## 1. 🏆 Workout-футер / чёрная полоса (iOS PWA) — РЕШЕНО после 22 деплоев
Тянулось с 23.06. Истинный корень оказался СТРУКТУРНЫЙ (не клавиатурный):
- `apple-mobile-web-app-status-bar-style: black-translucent` + `height:100%`/`100dvh` дают базовую высоту **812**, экран iPhone **874** → 62px снизу не закрашены = чёрная полоса (на всех табах, без клавы).
- Фикс: ВСЕ full-screen правила → `100vh` (html/body/#root/.app/.drawer/.detail-overlay/.token-gate/.wl-overlay).
- Симптом «футер всплывал при клаве» = отдельно: убран fixed-футер, «Завершить» = обычный элемент в конце скролла (`.wl-action`).
- Промежуточный «freeze body» = неверный диагноз, откачен.
Решено через **gsd-debug** (субагент) + on-device замеры + инспекция прода в CDP (pwa_token). Дебаг-сессия → `.planning/debug/resolved/` + `.planning/debug/knowledge-base.md`.
