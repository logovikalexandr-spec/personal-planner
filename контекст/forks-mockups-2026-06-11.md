# ФОРК-БРИФ: ДОВЕДЕНИЕ МОКАПОВ V3 ДО ГЛУБИНЫ T1 (2026-06-11)

> Фаза = **МОКАПЫ, не код.** Доводим каждую страницу V3 до эталона T1:
> **база + флоу (каждое касание) + состояния (пусто/загрузка/ошибка)**.
> Прораб координирует, каждый форк = своя страница (отдельные HTML → гонок нет).

## ЗАКОН ФОРКА
1. **Только мокапы (HTML).** Никакого кода (React/Python). Не трогать `planner-v2/`.
2. **Свои файлы.** Пиши ТОЛЬКО в `база-проекта-v3/pages/<твои файлы>`. 
3. **НЕ трогать shared:** `контекст/реестр-мокапов.md`, `база-проекта-v3/index.html`, чужие страницы. Реестр+галерею сводит ПРОРАБ после.
4. **Читать перед стартом (эталоны+контракт):**
   - `planner-v2/DESIGN.md` — токены/правила (onyx #0F0F11, ОДИН акцент ember #EE8A3C, Geist/Geist Mono, БЕЗ emoji, скелетоны не спиннеры, hairline не рамки).
   - `база-проекта-v3/pages/T5-flows.html` — **эталон ФЛОУ** (триггер → before/after-панели → note: зелёное=рекомендация, красное=деструктив).
   - `база-проекта-v3/pages/T1-состояния.html` — **эталон СОСТОЯНИЙ** (пусто/скелетон/ошибка по виду).
   - Свою базовую страницу (см. секцию) + строку контракта в `контекст/реестр-мокапов.md`.
5. **:root токены копировать 1:1** из T5-flows.html (единый визуальный язык, не изобретать палитру).
6. **Depth-first:** покрыть КАЖДОЕ взаимодействие и КАЖДОЕ состояние, не happy-path. Edge-кейсы обязательны.
7. **Модель (от Форка 0, уже в коде):** `Stage{order_index→этап N, status done|current|future|late, is_milestone, milestone_date, progress}`, `Project{success_probability%, target_date, ai_notes[{date,type:accelerate|risk|info,text}], weeks_left}`, `Task.stage_id`.
8. **ZERO-AFK:** AI-поля (success%/ai_notes/подсказка inbox) заполняет ИНТЕРАКТИВНЫЙ Claude в чате через write-API ИЛИ дешёвая эвристика. В UI НЕТ кнопки «сгенерить AI» с live-LLM. Показываем поля как отображение + ручной правки, не как live-генерацию.
9. **Выход:** `<PAGE>-flows.html` + `<PAGE>-состояния.html` (либо один файл с обеими секциями, если так чище). Бейджи фрейм/элемент как в T1 — опционально, прораб разметит при сводке.

## ФОРК T2 — КАЛЕНДАРЬ (`T2a-calendar-week` · `T2b-calendar-month` · `T2c-calendar-agenda`)
**База:** 3 вида готовы. **Цель:** флоу + состояния для всех трёх.
**Флоу покрыть:** переключение вид Неделя/Месяц/Лента · тап пустого слота/дня → создать задачу · тап задачи/события → деталь (DETAIL) · time-blocking: драг задачи в слот недели (перенос/ресайз) · свайп ◀▶ сосед-неделя/месяц · тап вехи-флажка → проект/этап · undated-tray (лоток недатированных) драг на сетку (если есть в базе) · кнопка «Сегодня» · тап дня в Месяце → панель дня/лента.
**Состояния:** пусто (неделя без задач / месяц / лента) · скелетон (сетка недели · сетка месяца · строки ленты) · ошибка+Повторить · нет вех.

## ФОРК T3 — ГАНТ (`T3a-gantt-all` · `T3b-gantt-project`)
**База:** 2 вида (все проекты / один проект). **Цель:** флоу + состояния.
**Флоу:** переключение Все↔Проект · тап полосы-этапа → деталь этапа · драг этапа = сдвиг дат · драг края = ресайз длительности · линии зависимостей (критпуть StageDependency) · зум таймшкалы День/Неделя/Месяц · тап вехи-ромба · горизонт-скролл таймлайна · линия «сегодня».
**Состояния:** нет проектов · проект без этапов · скелетон (полосы) · ошибка+Повторить.

## ФОРК T4 — ЦЕЛИ (`T4-celi` обзор · `T4d-celi-detail` деталь)
**База:** обзор-пульс + деталь. **Цель:** флоу + состояния.
**Флоу:** обзор-пульс → тап проекта → T4d деталь · в детали: %вероятности + срок + weeks_left (отображение; правка вручную ИЛИ написано Claude) · список этапов с progress · добавить этап · карточки ai_notes (accelerate/risk/info, разные цвета) · тап этапа → (Гант/деталь).
**ZERO-AFK:** %успеха и ai_notes — это ОТОБРАЖЕНИЕ того, что записал Claude в чате. НЕ кнопка «AI рассчитай» в приложении. Можно ручной override срока/%.
**Состояния:** нет целей/проектов · проект без этапов/без AI-данных (пусто-плейсхолдер «обсуди с ассистентом») · скелетон · ошибка.

## ФОРК DETAIL — ДЕТАЛЬ ЗАДАЧИ (`DETAIL-task`)
**База:** деталь есть (чеклист/сабтаски/повтор/напоминания из V2 F02). **Цель:** блок **«Этап проекта»** + состояния.
**Флоу:** задача С этапом → блок (кольцо n/m + «Этап 3 · Переговоры» + «Проект · до DD» + chevron «сменить») · задача БЕЗ этапа → «+ добавить этап» · тап chevron → шит выбора этапа (список этапов проекта) · убрать этап.
**Состояния:** задача без этапа (плейсхолдер-кнопка) · задача с этапом · шит выбора когда у проекта нет этапов (пусто «создать этап») · загрузка.

## ФОРК INBOX — ВХОДЯЩИЕ (`INBOX-inbox`)
**База:** триаж есть. **Цель:** AI-подсказка проект+этап + флоу + состояния.
**Флоу:** карточка-идея + блок «⚡ → проект ZIMA, этап 4» (из suggested_project_id + suggested_stage_id) + кнопка «Принять» (раскладывает в проект/этап) · быстрые чипы (в проект / на сегодня / дата / удалить) · свайп строки · идея БЕЗ подсказки (ручной разбор) · флоу принятия (куда уходит).
**ZERO-AFK:** подсказку даёт эвристика (keyword→проект, без LLM) ЛИБО Claude в чате. НЕ live-LLM на каждый элемент.
**Состояния:** пусто (всё разобрано) · идея без подсказки · скелетон · ошибка.
