# Реестр мокапов — единая адресация V2 ↔ V3

> Источник истины для ссылок на детали мокапов. Александр и Claude ссылаются кодами.
> **Бейджи вшиты в сами мокапы** (ember-пилюли): фрейм = `fcode`, элемент = `ecode`. Реестр = индекс + контракты.
> **Формат адреса:** `<версия> <страница> <фрейм><элемент>` — напр. `V3 T1 A4`, `V2 P01 A5`.
> - **версия** — `V2` (`база-проекта/`) или `V3` (`база-проекта-v3/`).
> - **страница** — код мокапа: V2 = `P01…P07` + фичи `F01…F18`; V3 = `T1, T2a/b/c, T3a/b, T4, T4d, T5, DETAIL, INBOX`.
> - **фрейм** = буква `A/B/C/D…` (бейдж `PAGE·A` в шапке фрейма).
> - **элемент** = буква+номер `A1, A2…` (бейдж на кнопке/фиче). Кросс-реф прямо в бейдже: `A1·F17` (бургер→шторка), `A6·P07`/`·DETAIL` (блок→деталь), `A7·D`/`A5·B` (→другой фрейм).
>
> **Статус разметки (11.06): ВСЁ размечено** — 33 мокапа: V2 страницы P01–P07, V2 фичи F01–F18, V3 T1/T2a/b/c/T3a/b/T4/T4d/T5/DETAIL/INBOX. Бейджи `fcode`/`ecode` в самих HTML. Ключевые кросс-рефы резолвятся: `·DETAIL`→F02, `A1·F17`→шторка, `F11`→T1·A-ядро.

## V3 P01 — Задачи (`T1-zadachi.html`) · A-коды [АКТИВНАЯ]

Контракт от 11.06. **Адрес = `T1 <фрейм><N>`** (бейджи вшиты в мокап). Фрейм = буква A/B/C/D, элемент = буква+номер.

### T1·A — таймлайн дня (главный фрейм)
| код | элемент | контракт |
|---|---|---|
| **A1** | ☰ бургер | открывает шторку (= **V2 F17**); edge-свайп тоже открывает; выбор в шторке = переход на экран «Список» |
| **A2** | чип-дата ⌄ | формат «вторник, 9 июня»; тап → датапикер **T1·B** |
| **A3** | чип «Сейчас»/«Сегодня» | две роли: на сегодня = «Сейчас» (скролл к now); на др. дне = «Сегодня» (прыжок на сегодня) |
| **A4** | саммари | «N задач · M закрыто»; прячется при 0 |
| **A5** | all-day зона | 2 чипа + «+N ещё» (тап раскрывает); прибита в sticky-шапке |
| **A6** | блок-задача | фон=проект, кант=приоритет, **метка этапа** (мишень+«этап N», цвет по статусу: current=ember·late=danger «!»·future=steel; нужен `task.stage_id` Форк 0; узкий блок=иконка, не тапается); чекбокс=done; тап блока=деталь (**P07**) |
| **A7** | FAB Список+[+] | пилюля «Список» только когда день=сегодня → открывает **T1·D**; иначе только [+]; [+]=quick-add |

**Жесты фрейма A:** свайп ◀▶ = сосед-день (и со старта на блоке, если перенос не взведён; край ≤24px = шторка; хинт исчезает после 1-го). Тап пустого часа = inline-черновик в ячейке (пишет на ВЫБРАННЫЙ день). Смена дня = мгновенный свап без скелетона + abort гонки.
**Ядро (reuse, не трогаем):** ресайз-грипы у активного блока, перенос long-press, колонки наложений (apple), now-линия.

### T1·B — датапикер (мини-месяц)
| код | элемент | контракт |
|---|---|---|
| **B1** | нав месяца ‹ › | листание месяцев |
| **B2** | сетка-тепло | заливка ячейки по нагрузке дня (зел=лёгкий·жёлт=средний·красн=забит **или** висят пропущенные важные·пусто=без цвета); today=ember-кольцо; **тап дня = сразу прыжок**. Пропущенные важные красят **ПРОШЛЫЙ день** где висят (зафикс. 11.06, дефолт). |
| **B3** | «Сегодня» | быстрый возврат на сегодня |

### T1·C — шторка (фрейм) = **V2 F17** (встроена инлайн). Коды внутри = коды F17.

### T1·D — вид «Список» (гибрид, открыт из A7; только день=сегодня)
**Контракт 11.06 (= стиль V2 P01·B):** два состояния. (1) начальное — простой quick-add бар. (2) при вводе задачи бар **разворачивается в токен-композер** как V2 P01·B: подсветка распознанных токенов в строке (`завтра`=accent-soft, `!1`=ember), чипы дата/приоритет/тег (активные=ember), ряд напоминание + круглый send, hint «распознано: дата·проект·приоритет·тег — тап по токену вернёт в текст». Строки-задач = **цветные карточки** (фон=проект-тинт, кант слева=приоритет), НЕ плоские. Прежний плоский вид T1·D отвергнут.
| код | элемент | контракт |
|---|---|---|
| **D1** | ‹ Таймлайн | назад в T1·A |
| **D2** | карта «Разобрать Inbox» | счётчик; → Inbox (**P06**) |
| **D3** | токен-композер | разворачивается при вводе; токены+чипы+напоминание+send+hint (=V2 P01·B) |
| **D4** | секция «Просрочено» | danger-лейбл; цветные карточки (проект-фон + приоритет-кант) |
| **D5** | секция «Без времени» | цветные карточки |
| **D6** | секция «Закрыто» | сворачивание |

### T1 — состояния (depth-гейт, зафикс. 11.06 · мокап `T1-состояния.html`)
- **T1·A таймлайн:** пусто = «План на день пуст. Тап по часу или + добавит» + бледная сетка · загрузка = скелетон шапки+блоков · ошибка = «Не удалось загрузить» + Повторить · (много задач/наложения = колонки, happy-path).
- **T1·D список:** пусто = «День свободен» + «Добавить задачу» · загрузка = скелетон карточек по секциям · ошибка = «Не удалось загрузить» + Повторить.

### T1 — scope Форка A (зафикс. 11.06)
- Строим: A1(бургер-открытие)·A2·B(датапикер)·A3(свайп)·A5(all-day+N)·A6(метка этапа, нужен Форк0)·A7(FAB Список)·A8(создание на выбр.день)·A9(свап)·D(Список=P01·B стиль)·состояния.
- **НЕ в Форке A:** F17-апгрейд шторки (свайп Изм/Удал, свободный цвет, корона/колокол/шестерня, emoji-проекты, empty) = отдельный таск. T1·A1 лишь открывает существующую шторку.
