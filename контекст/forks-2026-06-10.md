## ⚡ ZERO-AFK — главный архитектурный закон (с 2026-06-15 Anthropic делит биллинг)
**С 15 июня:** human-in-loop (ты в чате Claude Code) = по подписке, бесплатно. AFK (бэк/бот/вебхук/демон зовёт LLM в фоне без тебя) = платный кредит ≈ ставки API (выгорает ~×10 быстрее подписки). → `Alexandr/MEMORY.md` память «zero-afk».

**Закон для планировщика (и любого проекта):** приложение/бэкенд **НЕ зовёт LLM вообще**. Весь «AI» = ты + интерактивный Claude Code, который пишет результат в БД через write-API/CLI. Приложение = тупой-но-красивый трекер на FastAPI+PG. 0 LLM в проде → 0 AFK → 0 платы.

**Следствия:**
- `Project.ai_notes/success_probability/target_date` + `Stage` заполняешь ТЫ в чате («разбери проект X») → интерактивный Claude пишет через write-эндпоинты Форка 0. Это подписка.
- **«Петля ~5мин» = НЕ фоновый демон.** Приложение всегда показывает текущую правду из БД; разбор запускаешь руками on-demand. Никакого 24/7-мониторинга.
- **INBOX-подсказка (Форк G):** дешёвая эвристика в коде (keyword→проект, без LLM) ИЛИ проставляешь в чате. Live-LLM на каждый элемент = AFK, НЕ делать.
- Кросс-вопрос «как заполняются AI-поля» — **ЗАКРЫТ**: human-in-loop write-API, бэк LLM не зовёт.
