## 1. КОНТЕКСТ — ТОЛЬКО НУЖНОЕ

**Auto-load (старт сессии):**
- CLAUDE.md (этот файл) — правила + факты
- `MEMORY.md` — карта памяти (только индекс)

**По триггеру (явный вызов):**
- `[[дата]]` / «продолжим» → `контекст/сессии/YYYY-MM-DD.md`
- «полный контекст» / «deep dive» → `инструкции.md` + `docs/CLAUDE-reference.md` + нужный домен
- `[[X]]` в тексте → резолв атома: `сущности/*/X.md` / `решения/X.md` / `memory/X.md`
- «как работает <фича>» → атом экрана → обход его `[[связей]]` (компонент→модель→сервис)
- `/wrapup` → запись сессии + апдейт `memory/project-state.md`

**Граф атомов:** `сущности/` (экраны·компоненты·модель·сервисы) + `решения/` (ADR·концепты), связаны `[[wikilinks]]` с путём к коду. Полная таблица триггеров + маршруты «фича→код» → `docs/CLAUDE-reference.md`.

**НЕ грузить автоматом:** старые сессии, learnings.md, planner-bot (v1, архив).

## 4. КУДА ПИСАТЬ

- **Решение/выбор архитектуры** → `решения/<тема>.md` (атом, `[[wikilinks]]`)
- **Конец сессии** → `контекст/сессии/YYYY-MM-DD.md` + блок `## ── HANDOFF ──`
- **Статус проекта** (где встали) → `memory/project-state.md`
- **Правило от пользователя** → `memory/feedback.md` (+ **Why** + **How to apply**)
- **Инсайт/грабли** → `memory/learnings.md`
- **Новая запись → новая запись в `MEMORY.md`** (одна строка-указатель)

## 5. HARD RULES

1. **План перед действием** для нетривиального. Не глобальный рефактор без спроса.
2. **UI-first** для Mini App: mock UI → согласование → потом бэк.
3. **Визуальная проверка перед «готово».** Не верить deploy-хэшу — открыть и посмотреть.
4. **Depth-first** (см. TEAM.md): матрица состояний + edge + reuse-карта, не happy-path.
5. **С пользователем говорит только CEO-координатор** при agent-team сборке.
6. **Перед деструктивом** — подтверждение.
7. **Бесплатный/OSS стек.** Без платных подписок.
8. **Emoji — только иконка проекта/списка** через пикер (создание/изменение проекта, эталон V2 F07). Хром/нав/семантика — SVG. И в коде так же. (см. `planner-v2/DESIGN.md` §7).
9. **Lazy load.** Атомарно по wikilinks, не целые домены.
10. **Язык — русский.** Код и идентификаторы — английский. Документация — кириллица.
