# Продукт-аудит personal-planner + предложение реструктуризации

> 2026-06-09. Ресёрч: внутренний аудит (код+мокапы) ∥ внешний бенчмарк (9 топ-планировщиков). Перед /brainstorming.

## Диагноз (корень «тупо и слабо»)
Проблема НЕ в числе табов — их хватает. Три корня:
1. **Нет петли/ритуалов.** Табы не связаны в систему. У сильных (Sunsama) планирование/закрытие дня — это *процесс с шагами*, а не пустой экран. У нас — голый список.
2. **Роли экранов пересекаются.** «Обзор» (дашборд) ↔ Inbox ↔ Задачи ↔ Сегодня делят один вопрос. Канон: один экран = один вопрос.
3. **Календарь пассивный.** Только День, дублирует Today, нет связи с задачами (undated-tray, drag-to-block, Неделя). Сетка без задач = «туповато».

## Предложение: структура (7→5 табов, один экран = один вопрос)

| Таб | Единственный вопрос | Что внутри | Изменение |
|---|---|---|---|
| **Сегодня** | «что я делаю сейчас?» | выбранные на сегодня + таймлайн + вход в дневной ритуал + строка-сводка (N/закрыто/перегруз) | усилить ритуалом+ёмкостью |
| **Календарь** | «как дела ложатся во время?» | День/Неделя + **undated-tray слева** + **drag задачи в слот = блок** + resize | ПЕРЕДЕЛАТЬ (главный фикс) |
| **Задачи** | «где живут все задачи?» | весь бэклог по сферам/проектам + фильтры + поиск; **Inbox = smart-список/статус сверху** | слить Списки+Задачи+Inbox-таб |
| **Цели** | «зачем, движусь ли?» | objectives недели/квартала + прогресс + линк к задачам + **weekly review** | собрать с нуля |
| **Привычки** | «держу ли рутины?» | привычки **отдельной сущностью** + стрики + тепловая карта | собрать (Трекинг-стата сюда) |

**Убрать таб «Обзор» (дашборд):** аналитика — не ежедневный экран, а часть review. Сводка дня → строкой в «Сегодня», статистика → в «Цели»/weekly-review. Это и есть лечение «Обзор пересекается с Inbox». **Inbox** перестаёт быть отдельным табом → статус «не разобрано» + smart-список + обработка свайпом из любого места.

## Фичи по импакту (ТОП-10, от бенчмарка)

1. **Дневной ритуал план/шатдаун** — превращает список в систему (Sunsama). Наибольший разрыв.
2. **Оценка времени задачи + счётчик ёмкости с предупреждением** «8ч не влезает в 6ч» — лечит planning fallacy. Дёшево, мощно.
3. **Календарь: undated-tray + drag-to-block** — прямое лекарство от «туповат».
4. **Развести роли + убить «Обзор»** — один экран/вопрос.
5. **NL quick-add (+голос позже)** — захват за секунду (есть частично).
6. **Inbox как статус + быстрая обработка** свайпом (дата/проект/today/удалить).
7. **Привычки отдельной сущностью** — не повторяющиеся задачи (антипаттерн Reclaim).
8. **AI-предложение дневного плана** (Morgen-style: черновик→правишь) — ценнее полного авто-шедулинга для одного человека.
9. **Цели↔задачи явная связь** — objective→задачи→видно движение.
10. **Weekly planning + review** — верхний слой, самообучающаяся петля.

**Порядок чинки:** ритуалы → оценка времени/ёмкость → undated-tray-календарь → разведение ролей → цели/привычки.
