# Deep-спека — Inline-создание задачи в ячейке таймлайна

> Фаза 1 РАЗВЕДКА (product-depth). Артефакт-контракт ДО кода. Цель: владелец находит 0 дыр.
> Мокап-пара: `design/inline-cell/annotated-spec.html` (визуал+описание рядом), `flow-mockup.html` (поток).
> Дата: 2026-06-09. Ветка: planner-v2-phase0.

## 1. Цель
Тап/протяжка по пустой сетке таймлайна → черновик-блок растягивается на месте + инлайн-ввод названия там же (Apple Calendar-стиль). Заменяет текущий путь «тап часа → bottom-sheet TaskComposer». Захватываем только **название + время**; остальное — тап по блоку → TaskDetail.

## 2. Автомат состояний (FSM)

```
IDLE ──tap пустого часа──────────────▶ DRAFT_TAP(1ч, снап к часу)
IDLE ──pointerdown+move>CANCEL_PX────▶ DRAGGING(start фикс, end за пальцем)
DRAGGING ──pointerup──────────────────▶ DRAFT (снап 15м; если len<15м → 1ч)
DRAFT_TAP/DRAFT ──печать + Enter/Готово──▶ SAVING ──ok──▶ COMMITTED(обычный блок)
                                          └──fail──▶ ERROR(текст цел, Повторить)
DRAFT(пусто) ──тап-вне/Esc/смена-таба──▶ IDLE (отмена, ничего не создано)
DRAFT(есть текст) ──тап-вне───────────▶ SAVING (авто-коммит) [решение ниже]
ERROR ──Повторить──▶ SAVING
```

Инвариант: **один черновик за раз**. Открытие нового при существующем пустом — старый отбрасывается; при непустом — старый сначала коммитится.

## 3. Таблица состояний

| Состояние | Что на экране | Доступные действия | Выходы |
|---|---|---|---|
| IDLE | сетка + хинт (если нет блоков/черновика) | тап / протяжка / скролл | DRAFT_TAP, DRAGGING |
| DRAGGING | пунктир-блок растёт за пальцем, live-подпись времени | тянуть, отпустить | DRAFT |
| DRAFT | пунктир ember-блок, инпут автофокус, плейсхолдер, клавиатура, «Готово» | печать, Enter/Готово, тап-вне, Esc | SAVING, IDLE |
| SAVING | блок без id, лёгкий disabled-вид (без спиннер-мигания) | — | COMMITTED, ERROR |
| COMMITTED | обычный блок (тинт проекта / кант приоритета) | тап→TaskDetail, ресайз/перенос, чек | (как любой блок) |
| ERROR | красная рамка, текст цел, «Не сохранено · Повторить» | Повторить, тап-вне | SAVING, IDLE? |

## 4. Edge-кейсы (явные решения)

| # | Кейс | Решение |
|---|---|---|
| E1 | Тап по существующему блоку | Открыть его (TaskDetail), НЕ создавать. Жест на `.cal-block` ≠ на `.cal-hour`. |
| E2 | Протяжка вверх (end<start) | Нормализуем: min=start, max=end. |
| E3 | Протяжка < 15 мин (≈тап) | Трактуем как тап → блок 1ч. |
| E4 | Протяжка за нижний край видимой области | Авто-скролл сетки + `clamp` end до `DAY_END`. |
| E5 | Клавиатура перекрывает черновик | `scrollIntoView` блока над клавой + scroll-lock фона (паттерн есть). |
| E6 | Второй тап при открытом ПУСТОМ черновике | Старый отбросить, новый на новом месте. |
| E7 | Второй жест при НЕПУСТОМ черновике | Сначала коммит текущего, потом новый. |
| E8 | POST упал | ERROR: текст+время сохранены, «Повторить». НЕ показываем как создано. |
| E9 | Смена таба / перезагрузка с открытым черновиком | Пустой → отбросить. Непустой → авто-коммит (как тап-вне). |
| E10 | Старт черновика до 05:00 (сетка с 05:00) | Сетка уже авто-растягивается вниз к раннему часу (есть в DayTimeline). |
| E11 | Наезд / пересечение блоков (включая черновик) | **Колонки (Apple), РЕШЕНО владельцем.** Пересекающиеся блоки делят ширину: 2 наложения = пополам, N = на N колонок. Draft участвует в раскладке. См. §12. |
| E12 | Тап-вне у DRAFT с текстом | **РЕШЕНО (владелец): авто-коммит** (как Apple). Тап-вне с непустым текстом → SAVING. Пустой → отмена. |

## 5. Аудит согласованности (vs существующее)

- **Жесты блоков:** создание-протяжка использует ту же pointer-инфру (capture, `startBlocking`, `CANCEL_PX`, `PX_PER_MIN`, snap-на-отпускании), что ресайз/перенос. Единый стиль движения — не должно «дёргаться» иначе.
- **Сущность:** созданный блок === задача из композера/quick-add. Один тип → одно поведение (PATTERNS.md). Тап = TaskDetail везде.
- **Цвет-канон:** новый блок без проекта = `--surface-2`, без приоритета = нет канта (как все).
- **Замена, не добавление:** `onTapHour → bottom-sheet` УБИРАЕТСЯ для пустого часа (заменён инлайном). FAB `+` / quick-add остаются как путь без времени.

## 7. Контракт данных / API

POST создать: `{ title, due_date=<today ISO>, due_time="HH:MM:00", end_time="HH:MM:00", project_id=null, priority="none" }`. Ответ → задача с `id` → заменяет draft. Бэкенд-эндпоинт создания уже существует (проверить сигнатуру в api.ts перед сборкой).

## 8. Критерии приёмки

- [ ] Тап по пустому часу → блок 1ч с автофокус-инпутом на снапнутом часе.
- [ ] Протяжка → блок нужной длины, снап 15м, нормализация вверх.
- [ ] Enter/Готово с текстом → задача создана, блок обычный, тап → TaskDetail.
- [ ] Пустой + тап-вне/Esc → черновик исчез, задача НЕ создана.
- [ ] POST упал → текст цел, «Повторить» работает.
- [ ] Тап по существующему блоку открывает его (не создаёт).
- [ ] Клавиатура не перекрывает черновик; фон не скроллится.
- [ ] Создание-протяжка не «дёргается» (тот же фид, что ресайз).
- [ ] Все edge E1–E12 покрыты.

## 9. Тест-лист (TDD — сначала тесты)

**Чистые функции (юнит, до UI):**
- `pointerToMinutes(y, offsetMin)` → минуты; снап; clamp в границы дня.
- `normalizeRange(start, end)` → swap если end<start; min-длина 15м; <15м→60м (тап).
- `defaultRange(tapMin)` → [снап(tapMin), +60].
- payload-билдер: минуты → `due_time/end_time` `HH:MM:00`, due_date=today.

**Поведение (компонент/e2e harness):**
- tap empty → draft 1ч; drag → draft N; commit→POST payload верный; cancel пустого; error-retry; tap-on-block → onOpen не create.

**Бэкенд:** create уже покрыт (Волна 2, 105 pytest) — добить тест на отсутствие проекта/приоритета если нет.

## 11. Доработки после обзора (design-review + 2 адверсариальных агента, 2026-06-09)

Codex CLI недоступен → независимый обзор 2 Claude-агентами (дизайнер + инженер). Совпавшие CRITICAL закрыты ниже. Исходные оценки: дизайн-готовность 4/10, инженер — 4 критдыры. После фиксов ниже → ~9/10.

### CRITICAL (закрыто)
- **C1. Жест тап-vs-протяжка-vs-скролл-vs-блок.** Создание ловим на `pointerdown` по `.cal-hour` (пустота), НЕ по `.cal-block`. Тап (move<`CANCEL_PX` 12px) = блок 1ч **немедленно, БЕЗ long-press** (long-press 220мс — только перенос существующего). Move>`CANCEL_PX` вниз = протяжка-создание. Move>порога без явного создания = скролл (как сейчас).
- **C2. Клавиатура + scroll-lock (iOS WebView).** При фокусе инпута: (1) выставить `App.anyOverlay`/scroll-lock (паттерн оверлеев) ДО подъёма клавы; (2) `scrollIntoView({block:"center", behavior:"auto"})` вызывать в `useEffect` ПОСЛЕ `input.focus()`, чтобы блок+подпись времени были целиком видны над клавой; (3) `--kb-inset` через `visualViewport` (iOS не ресайзит layout viewport — см. telegram.ts); (4) инпут `pointer-events:auto` + `touch-action:manipulation` — touchmove-гаситель НЕ должен глушить ввод.
- **C3. API-контракт (подтверждён в коде).** `createTask(title, opts)` принимает `{due_date, due_time, end_time, project_id?, priority?}` → возвращает `Task{id,...}`. Инлайн шлёт `due_date=today, due_time, end_time, project_id=null, priority="none"`, **без `parent_task_id`** (не сабтаск). Ошибка → ERROR-ветка. На успехе draft (`id:null`) заменяется на ответ с `id`.
- **C4. Гонка SAVING.** В SAVING: инпут `disabled` (opacity .6), «Готово» disabled, **тап по блоку НЕ открывает** (`onOpen` гард: нет `id` → no-op), повторный коммит заблокирован (нет двойного POST). Таймаут ~5с → ERROR.

### HIGH (закрыто)
- **H1. Draft визуально ОТЛИЧЕН от обычного блока — намеренно.** Draft = пунктир `--accent` 1.5px + фон `--accent-soft`. Обычный блок = сплошной, тинт проекта/`--surface-2`. Юзер всегда видит «это ещё не сохранено». После коммита → обычный вид.
- **H2. Состояния SAVING и DRAGGING — в мокап.** DRAGGING: инпут уже в блоке, но `disabled`/read-only (на отпускании активируется, autofocus, без delay — непрерывность жеста). SAVING: см. C4. Добавлены кадры в annotated-spec.html.
- **H3. Где живёт draft-state.** В `Today` (подъём из DayTimeline), один черновик. Смена таба: непустой → авто-коммит (E9), пустой → отброс. Reload/смена экрана = отброс (эфемерно, без localStorage — MVP).
- **H4. Математика при авто-скролле во время протяжки.** Минуты считать от абсолютной позиции в сетке (`getBoundingClientRect` грида + `scrollTop`), НЕ от сырой `clientY`-дельты (иначе сдвиг при авто-скролле у края). 
- **H5. `startBlocking` — глобальный listener.** Рефактор на счётчик/registry, чтобы создание и ресайз не вешали два `touchmove`-listener'а (хоть одновременно и не бывают по UX).
- **H6. Тач-таргеты 44px.** Инпут draft min-height 44px; «Готово» min 44px (input-accessory над клавой).

### MEDIUM (решения)
- **M1. Создание до 05:00:** MVP — нельзя инлайном раньше `START_HOUR` (редко; через композер). Авто-растяжка сетки draft'ом — не в MVP.
- **M2. Esc / Android back:** `onKeyDown` Escape → отмена пустого; back-кнопка интегрируется в App-flow закрытия оверлеев.
- **M3. Error-retry:** таймаут 5с, до 3 попыток, дальше «Попробуй позже». Текст всегда цел.
- **M4. Плейсхолдер «Новая задача»** гаснет на первом символе; «пусто» = `value.trim()===""`.
- **M5. Микро-фидбек:** на коммите блок pulse scale 1→1.02→1 ~200мс (DESIGN motion 120-160мс — выдержать).

## 12. Раскладка наложений — колонки (Apple), РЕШЕНО

Касается ВСЕХ блоков со временем (не только inline-создания) — отдельный кусок рендера таймлайна.

- **Алгоритм:** для видимого набора timed-блоков (+ активный draft) найти кластеры пересекающихся по времени; внутри кластера назначить колонки (lane assignment / interval-graph greedy), ширина блока = (right-left)/N_колонок_в_кластере, позиция X по индексу колонки.
- **Затрагивает:** обычный рендер, draft/DRAGGING (черновик встаёт в свою колонку live), ресайз/перенос (на изменении времени — пересчёт колонок кластера; на отпускании — финальная раскладка).
- **Жесты в узкой колонке:** края-ресайз и тап остаются рабочими при уменьшенной ширине (тач-таргет высоты не меняется; ширина ≥ ~84px при 2 колонках на 390px — ок).
- **MVP-границы:** глубина наложения разумно ограничена (напр. до 3–4 колонок; при большем — горизонтальный скролл кластера или «+N» не в MVP, флаг).
- **Тесты (чистая функция раскладки):** `layoutColumns(blocks)` → для каждого блока `{colIndex, colCount}`; кейсы: нет наложений (1 колонка во всю ширину), 2 полных, частичное (A∩B, B∩C, A∌C → A,C могут делить колонку), вложенный, цепочка, draft в кластере.
