# Planner v2 — Design System

Источник: референс пользователя — TickTick, тёмная тема, оранжевый акцент. Без emoji в этом файле.

## Принципы
- Тёмная тема по умолчанию (как в референсе). Не подхватываем светлую тему Telegram — бренд фиксированный.
- Оранжевый — единственный акцент. Остальное нейтральное (почти чёрный фон, белый текст, серый muted).
- Строки-списки: иконка слева, название, счётчик/мета справа. Высокая плотность, но воздух между группами.
- Минимум хрома: тонкие разделители, без тяжёлых рамок и теней. Карточка/строка отделяется фоном, не бордером.
- Нативное ощущение: системный шрифт (SF/Segoe/Roboto) — для Telegram Mini App это правильно, совпадает с TickTick.

## Токены (CSS-переменные)
```
--bg:          #1a1a1c   /* фон приложения, почти чёрный */
--surface:     #242426   /* строки, карточки */
--surface-2:   #2c2c2e   /* приподнятые элементы, инпут */
--text:        #ffffff   /* основной текст */
--text-muted:  #8e8e93   /* счётчики, мета, второстепенное */
--accent:      #f5821f   /* оранжевый — акцент, активный таб, done, кнопки */
--accent-soft: rgba(245,130,31,0.16)  /* тинт выделенной строки */
--border:      #2e2e30   /* тонкие разделители */
--danger:      #ff453a   /* приоритет high / удаление */
--warning:     #ffb02e   /* приоритет medium */
--radius:      12px
--radius-sm:   10px
--gap:         12px
--tab-h:       64px
--font: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
```

## Типографика
- База 16px / line-height 1.4.
- Заголовок экрана: 22px / 700.
- Строка списка: 16px / 500 название, 14px muted мета.
- Счётчики справа: 15px, --text-muted.

## Компоненты
- Строка задачи: круглый чекбокс слева (22px, бордер --border; done = заливка --accent). Название; под ним мета (дата/время) 13px muted. Левый цветной кант по приоритету (high=danger, medium=warning, low=accent, none=нет).
- Таб-бар: фон --surface, верхний бордер --border, активный таб — текст/иконка --accent. Бейдж Inbox — оранжевый кружок со счётчиком.
- Кнопка primary: фон --accent, текст #fff, радиус --radius-sm, высота >=44px. Ghost: прозрачная, текст --accent.
- Инпут: фон --surface-2, без видимого бордера (или --border 1px), радиус --radius-sm.
- Выделенная строка (активный смарт-список): фон --accent-soft, текст --accent.
- Пустое состояние: по центру, muted-текст + одна primary-кнопка действия.

## Движение
- Переходы 120-160ms ease для фона/непрозрачности (таб-переключение, нажатия). Без декоративных анимаций.
- Нажатие: лёгкое затемнение/scale 0.98 на active.

## Что НЕ делаем
- Не тянем themeParams Telegram в цвета (фиксируем тёмную тему).
- Без градиентов, без декоративных блобов, без иконок-в-кружках как украшения, без 3-колоночных сеток. Это таск-менеджер, не лендинг.
