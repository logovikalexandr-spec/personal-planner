# Design System: Planner v2

> Прогнано через taste-design. Источник вайба: TickTick (тёмная тема, оранжевый акцент) + фон уровня Onyx как в Ledger. Это APP UI (личный таск-менеджер), не лендинг — правила hero/асимметрии лендингов не применяются. Без emoji в коде и в этом файле.

## 1. Visual Theme & Atmosphere
Тёмный, плотный, спокойный daily-app. Почти чёрный onyx-холст, единственный тёплый акцент (ember-оранжевый), белый текст, стальной muted. Поверхности отделяются фоном и тончайшими hairline-разделителями, не рамками и не тенями. Ощущение нативного приложения: быстрый, тактильный, без украшательства. Density 6 (списки задач плотные, но между группами воздух). Variance 3 (утилита — предсказуемая сетка). Motion 4 (сдержанный spring, тактильные нажатия, без декоративных циклов).

## 2. Color Palette & Roles
- **Onyx Canvas** (#0F0F11) — основной фон экрана. Никогда не #000000.
- **Smoke Surface** (#1A1B1F) — строки задач, карточки, таб-бар.
- **Slate Raise** (#242529) — инпут, приподнятые элементы, чипы.
- **Bone White** (#F4F4F5) — основной текст, заголовки.
- **Steel Muted** (#8A8B91) — счётчики, даты, мета, второстепенное.
- **Ember Accent** (#EE8A3C) — единственный акцент: активный таб, done-чекбокс, primary-кнопка, фокус, бейдж. Тёплый оранжевый, saturation < 80%, без неона.
- **Ember Soft** (rgba(238,138,60,0.16)) — тинт выделенной/активной строки.
- **Signal Red** (#FF5C5C) — приоритет high, удаление. Сдержанный, не пожарный.
- **Amber Mid** (#FFB02E) — приоритет medium.
- **Hairline** (rgba(255,255,255,0.07)) — 1px разделители, верх таб-бара.
(Максимум 1 акцент. Запрещено: #000000, фиолетовый/неон, радужные градиенты, glow.)

## 3. Typography Rules
- **Display/Body:** `Geist` — track-tight, иерархия весом и цветом, не гигантским размером. Заголовок экрана 22px/700, строка 16px/500.
- **Mono:** `Geist Mono` — счётчики, даты, время, плотные числа (бейджи, мета задач).
- **Banned:** `Inter`, системный шрифт как основной для premium-контекста, любые serif в UI.
- Base 16px / line-height 1.4. Min touch text 14px.

## 4. Component Stylings
- **Строка задачи (Row):** фон Smoke Surface, радиус 12px, без бордера. Круглый чекбокс 22px слева (бордер Hairline; done = заливка Ember + белая галочка). Название Bone White; мета (дата/время) Geist Mono 13px Steel. Левый inset-кант 3px по приоритету (high=Signal Red, medium=Amber, low=Ember, none=нет). Active: scale 0.98.
- **Buttons:** primary — плоская заливка Ember, текст белый, радиус 10px, >=44px, тактильный translate/scale на active, без outer glow. Ghost — прозрачная, текст Ember.
- **Chips (фильтры/проекты):** пилюля, фон Slate Raise + Hairline; active = Ember Soft фон + Ember текст, бордер убран.
- **Inputs:** фон Slate Raise, бордер Hairline, радиус 10px, фокус-ринг Ember. Лейбл над полем (если есть), ошибка под полем. Без floating-label.
- **Tab bar:** фон Smoke Surface, верх Hairline, активный таб — Ember. Бейдж Inbox — Ember кружок, число Geist Mono.
- **Loaders:** скелетоны, повторяющие размеры строк (shimmer), НЕ круглые спиннеры.
- **Empty states:** по центру, спокойный muted-текст + одна primary-кнопка действия. Не «нет данных».

## 5. Layout Principles
- Mobile-first, один вьюпорт (Telegram Mini App). Никакого горизонтального скролла.
- CSS Grid/Flex по месту; таб-бар фиксирован снизу, контент с padding-bottom под него + safe-area.
- Внутренние отступы экрана 16px, gap между строками 8px, между группами 16-24px.
- min-height: 100% / 100dvh, не h-screen.
- Без перекрытий: каждый элемент в своей зоне. Без 3-колоночных равных сеток-карточек.

## 6. Motion & Interaction
- Переходы 120-160ms, ease/spring (ощущение веса). Без linear.
- Нажатие: translate/scale 0.98 + лёгкое затемнение.
- Анимируем только transform/opacity (hardware-accelerated). Не top/left/width/height.
- Списки можно вводить лёгким staggered-fade (опц.), без навязчивых вечных циклов.

## 7. Anti-Patterns (Banned)
- Без emoji в UI.
- Без `Inter` и системного шрифта как основного; без serif.
- Без чистого #000000.
- Без неона/outer-glow теней, без пересыщенных акцентов, без градиентного текста.
- Без иконок-в-кружках как декора, без 3-колоночных равных карточек.
- Без кастомных курсоров, без перекрытий элементов.
- Без фейковых данных/метрик и без «LABEL // YEAR».
- Без AI-клише в текстах («Elevate», «Seamless», «Unleash»).
- Без круглых спиннеров — только скелетоны.
