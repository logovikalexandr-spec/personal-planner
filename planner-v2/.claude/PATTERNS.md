# Реестр UX-паттернов planner-v2

> Единый источник согласованности. Одна сущность ведёт себя ОДИНАКОВО везде. Фаза 1 РАЗВЕДКА сверяется с этим файлом; Фаза 3 обновляет (новый/изменённый паттерн → запись сюда). Если фича вводит новое поведение там, где паттерн уже есть — это рассинхрон (reviewer: BLOCK).

Формат записи: **Паттерн** — правило поведения · *где живёт* · статус.

## Шторки (bottom sheet, `Sheet.tsx`)
- **Swipe-to-close только из грип-зоны** (верх ~56px), не из тела (чтобы не конфликтовать со скроллом контента). · все picker'ы (project/priority/tag/date) · ✅ единый `Sheet.tsx`.
- **Стопка шторок** — каждая новая поверх; закрытие возвращает к предыдущей, не схлопывает всё. · composer-пикеры · ⚠️ z-index/портал-долг, не плодить.

## Выбор (selection)
- **Single-select: тап по опции = `onPick(x)` + `onClose()`** (выбор закрывает шторку), с микро-паузой ~140мс (подсветка+✓, потом закрыть, DESIGN §6). · ProjectPickerSheet, PriorityPicker · решено 2026-05-30 (picker Фаза 1).
- **Multi-select: тап = toggle, закрытие по явной кнопке «Готово»** (НЕ закрывать на каждом тапе). · TagPickerSheet · ✅.
- **Создание сущности из picker'а: строка «+ Новый …»** открывает создающий sheet (убирает тупик пустого состояния). · TagPicker (тег), Drawer/Lists (+Проект); → добавить в ProjectPicker · частично.

## Дерево проектов
- **Дерево как контейнер (выбор проекта задачи):** всегда-развёрнутое плоское дерево с отступами, тап по любому узлу (включая родителя) = выбор. Родитель — валидный проект. Без chevron. · ProjectPickerSheet · решено 2026-05-30.
- **Дерево как навигация (Drawer/Lists):** сворачиваемое (expanded:Set + chevron-toggle), тап по строке = навигация/выбор списка БЕЗ закрытия, chevron = раскрыть. · ProjectTree (Drawer, Lists) · ✅.
  - *Разные режимы намеренны* (picker = быстрый выбор; Drawer/Lists = управление структурой). Но логика построения дерева — ОДНА: `lib/projectTree.ts` `flatten(projects, expanded?)` (вынести из 3 копий: pickers, ProjectTree, Drawer). · ⚠️ дубль, к выносу.
- **Отступ вложенности: clamp `min(depth,3)`** — имя читаемо на узком экране. · picker · решено 2026-05-30.

## Приоритет
- **Кант приоритета = левый inset 3px:** P1=high Signal Red `#FF5C5C` / P2=medium Amber `#FFB02E` / P3=low Ember `#EE8A3C` / P4=none нет. Единый источник `task.priority`. · TaskItem (`.prio-*`), DayTimeline (border-left) · ✅ (волна 1).
- **Идентичность проекта = цвет + emoji-данные** (proj.icon emoji остаётся, хром — SVG). Кант приоритета важнее цвета проекта при конфликте. · TaskItem, DayTimeline · ✅.

## Иконки / хром
- **Хром = SVG, данные = emoji.** Навигация/индикаторы/глифы — SVG (color-swap active=Ember, width 2). Пользовательские emoji проектов/категорий — остаются. · icons.tsx · ✅ (волна 1).
- **Скелетоны, не спиннеры** при загрузке. · DESIGN §7 · обязательно везде.

## Состояния (минимум на каждый экран/компонент)
пусто (с CTA, не тупик) · загрузка (скелетон) · ошибка (отличима от пусто, ретрай) · выбрано · край (длина/глубина/0/много).
