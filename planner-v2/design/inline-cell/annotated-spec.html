Inline-создание задачи в ячейке — аннотированная спека

Мокап + описание окна и фич РЯДОМ с каждым состоянием. Apple-стиль, заменяет bottom-sheet по тапу часа.
Читается слева-направо как поток: покой → жест → черновик → ввод → создано (+ edge: отмена / ошибка).

Модель — единый контракт

ЖестТап пустоты = блок 1ч на снапнутом часе · протяжка = start→end (снап 15 мин на отпускании). Что вводимТолько название + время. Быстро, на месте. Всё прочееПроект / приоритет / напоминания / повтор / сабтаски / чеклист / заметки — тап по блоку → TaskDetail (уже есть, Волна 2). Новой формы НЕ делаем. КоммитEnter или Готово с непустым текстом → POST {title, due_date=today, due_time, end_time} → блок становится обычным. ОтменаПустой текст + (тап-вне / Escape / смена таба) → черновик исчезает, ничего не создаётся. Reusey↔минуты (PX_PER_MIN,offsetMin), snap15, clamp, hhmm, гаситель скролла, pointer-capture — всё из DayTimeline. Новое: draft-state без id + инлайн-input + POST.

1 · ПОКОЙ

Пустая сетка

Окно
Таймлайн дня (как сейчас). Пустые часы кликабельны.
Подсказка
Тонкий хинт в пустой области: «тап = 1ч, протяжка = своя длина». Гаснет когда есть хоть один блок или черновик.
Что доступно

Edge: тап по существующему блоку = открыть его (TaskDetail), НЕ создать. Различаем: жест начат на пустом .cal-hour vs на .cal-block.

4 · СОЗДАНО

Обычный блок (это и есть твой вопрос)

Переход
Имя введено + Enter/Готово → POST → черновик превращается в обычный блок, клавиатура уходит.
Вид
Сплошной (не пунктир): фон = тинт проекта (пока нет проекта → серый --surface-2), кант слева = приоритет (пока none → нет канта).
Тап по блоку
→ TaskDetail: проект, приоритет, напоминания, повтор, сабтаски, чеклист, заметки. Тот же экран, что у любой задачи — настраиваешь как обычно.
Края / тело
Ресайз времени за края, перенос long-press — жесты уже работают.
Согласованность: после создания блок НЕ отличается от созданных через композер/quick-add. Один тип сущности — одно поведение везде (закон PATTERNS.md).

5 · EDGE — POST УПАЛ

Ошибка сохранения

Триггер
Сеть/сервер не ответил на создание.
Поведение
Блок остаётся с введённым текстом и временем (ничего не потеряно), красная рамка, строка «Не сохранено · Повторить».
Доступно
Повторить → новый POST · тап-вне = оставить черновик (не теряем) или отменить — уточнить в спеке.
Почему так: терять напечатанное при сетевом сбое = худший UX. Оптимистично НЕ показываем как «создано», пока сервер не подтвердил id.

4.5 · SAVING

Идёт сохранение (POST летит)

Вид
Блок приглушён (opacity .6), подпись «сохранение…». Без яркого спиннера. Инпут и «Готово» disabled.
Блокировки
Тап по блоку НЕ открывает (нет id → no-op). Повторный коммит заблокирован → нет двойного POST.
Выход
ok → обычный блок (сост.4, micro-pulse) · fail/таймаут 5с → ERROR (сост.5).
Почему критично: без видимого SAVING юзер думает «не сработало», тапает ещё → дубль-задача. Приглушение = «принято, погоди».
