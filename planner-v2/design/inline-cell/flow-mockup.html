Состояния: покой → (тап|протяжка) draft → ввод → создан | отмена | ошибка.
Жесты: тап пустоты = блок 1ч на снапнутом часе · протяжка = start→end (снап 15м, на отпускании) · тап по существующему блоку = открыть (как сейчас).
Коммит: Enter/Готово с текстом → POST (due_time+end_time, дата=сегодня, без проекта/приоритета) → блок становится обычным.
Отмена: пустой текст + тап-вне/Escape/смена-таба → draft исчезает, ничего не создаётся.
Edge: протяжка вверх → start/end нормализуются · нулевая протяжка = тап = 1ч · клавиатура: draft скроллится над ней, фон залочен · POST упал → draft с текстом остаётся + «Повторить» (текст не теряется).
Reuse: y↔минуты (PX_PER_MIN/offsetMin), snap15, clamp, hhmm, гаситель скролла, pointer-capture — всё из DayTimeline. Новое только: draft-state без id + инлайн-input + POST.
