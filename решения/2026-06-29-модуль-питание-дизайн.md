# Модуль «Питание» — дизайн v1 (спека)

**Дата:** 2026-06-29 · **Статус:** утверждён мокапами Александра (контракт) · **Проект:** planner-v2
**Близнец:** структурно зеркалит модуль «Тренировки» (`WorkoutLog`) — Цель→Этап→Неделя→День→элементы.

## Цель

Вкладка «Питание» в трекере под набор массы. Видеть цель в массе, прогресс этапа/недели/дня
по ккал и БЖУ, по дням — приёмы пищи (пред-засеяны идеальным меню), отмечать съеденное,
видеть сумму vs цель. Убить тедиум ручного ведения: меню составляет Claude (пишет в базу),
обычный день = тап «съел как план».

## Контракт (мокапы Александра, 2026-06-29)

3 экрана, собираем 1:1 по раскладке. Приземление идеал-мокапа на v1 — см. «Дельты».

### Экран 1 — Питание (обзор)
- Хедер «Питание» / подзаголовок имя цели · шестерёнка.
- **Карточка цели:** `Цель: 80.6 → 95 кг` · `Этап 1 · Набор массы` · `Неделя N из 12` · % + прогресс-бар (ember).
- **Карточка «Сегодня · DD месяц»** + бейдж статуса («В пути»/«Выполнено»):
  - Кольцо % дня (ккал-факт/цель).
  - `2 450 / 3 200 ккал` + бар.
  - Триплет макро: `Б 145/170 г · 85%` · `У 280/390 г · 72%` · `Ж 72/85 г · 85%` (зелёный/синий/жёлтый %).
  - Строка «До цели осталось»: N г белка · N г углеводов · N г жиров · ≈N ккал.
- **Карточка «Неделя · DD–DD»** `4 из 7 дней`: кружки дней Пн–Вс (✓+% выполнен / →+% текущий ringed / — запланирован).
- Строки-переходы: «Итоги недели» · «История · Все недели и этапы».
- Кнопка `+ Добавить приём пищи` + иконка камеры.
- Низ: вкладка «Питание» активна.

### Экран 2 — День
- Хедер «Среда · DD месяц» / «Сегодня» · назад.
- Та же карточка кольцо+макро+«до цели осталось».
- **«Приёмы пищи»** — стопка строк, каждая: `время · название · бейдж(Выполнено/Запланировано) · Б/У/Ж · ккал · фото-превью · шеврон`.
  - Приёмы из шаблона: Завтрак / Перекус / Обед / После тренировки / Ужин / Перед сном (время+БЖУ из меню).
  - Тап строки → деталь приёма (что в нём, отметить съел / заменить).
- Кнопка `+ Добавить приём пищи` + камера.

### Экран 3 — Неделя
- Хедер «Неделя» / имя цели · иконка календаря.
- `Эта неделя · DD–DD` `4 из 7 дней` + прогресс-бар.
- Строки дней: `кружок-статус · день·дата · ккал/цель · Б/У/Ж · % · бар`. Текущий день ringed (ember).
- Кнопка «Итоги недели».

## Дельты идеал-мокапа → v1 (приземление)

1. **Цифры:** мокап 82→95 / «Рекомпозиция». Реально **80.6→95 / «Набор массы»** (цель id=23).
2. **Фото блюд = ФАЗА 2.** Распознавание фото→БЖУ требует ИИ-в-петле — паркуем. В v1 приёмы **без
   реального фото-превью** (плейсхолдер-иконка по типу блюда). Камера-кнопка в v1 = ручной ввод/заглушка.
3. **Навигация:** добавляем только **вход «Питание»** в нижнюю навигацию (как сейчас сделаны Тренировки).
   Полную перестройку на 5 табов (Прогресс/Профиль) НЕ делаем.

## Архитектура данных (зеркало workout-схемы)

- `nutrition_target` (или поля на этапе/цели): дневные цели — kcal 3000–3200, protein 160–180,
  fat 70–90, carb 350–420. Привязка к project_id=23 / этапу.
- `meal_template` — идеальный день: список приёмов. **Сеет Claude (write в БД).**
- `meal_template_item` — приём шаблона: order_index, time, name, целевые ккал/Б/Ж/У (или состав из продуктов).
- `product` — библиотека продуктов с БЖУ/100г. **Сеет Claude** (регулярные: Skyr, творог, курица, рис, овсянка, протеин...).
- `meal_log` — факт по дню: дата, приём, статус (planned/done), ккал/Б/Ж/У (по умолчанию = план), опц. состав.
- День засевается из `meal_template` при первом открытии (как сессия из workout_template).

**Замена блюда (v1, без фото):** выбор из `product` + граммы → БЖУ считается. Минимум тедиума.
