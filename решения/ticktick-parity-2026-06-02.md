# Решение: курс на паритет с TickTick (single-user)

> Зафиксировано 2026-06-02. Контекст: владелец попросил довести planner-v2 «до атомов» как полноценный TickTick. Проведена РАЗВЕДКА (5 доменов TickTick) → [[2026-06-02-ticktick-teardown-and-roadmap]] (`planner-v2/docs/superpowers/specs/`).

## Что решено
1. **Охват = ядро сначала**: волны 2→3→4→5 (TaskDetail+ядро задачи · Списки · Календарь · Today+жесты). Goals/Tracking — после.
2. **Структура = папки + списки (TT-модель)**, миграция с `project.parent_id`-дерева. Папка = контейнер 1 уровня.
3. **Tracking = Habits + Статистика + Матрица + Countdown.** Pomodoro/Focus — ВЫКИНУТ.
4. **Внешний календарь — DROP.** Источник истины задач Александра = **Notion** → синхронизация Notion = отдельная волна ПОСЛЕ ядра.

## Принцип
Клонируем поведение+ощущение TickTick, снимаем все премиум-замки (single-user = всё бесплатно), выкидываем аккаунты/коллаборацию/лимиты.

## Открыто
- Notion-sync запаркован (после вол.5). Вся БД задач владельца уже в Notion.
- Точные hex приоритетов / NL-грамматика — проверить в живом TT при пиксель-клоне.
