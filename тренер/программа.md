# Программа тренировок — Recomp 90 дней

> Источник истины для агента-тренера. Цель: сильнее + мощная красивая фигура.
> Стратегия — **рекомпозиция**: строим мышцы (спина/дельты/верх груди), сушим талию.
> База = **реальная программа Александра** (его упражнения и веса из логов 23.05–02.06) + фиксы тренера.
> Связано: [[роль]], [[память]]. Дни — **плавающие, 4×/нед** (привычка «Зал» = weekly_n 4).

---

## 0. Вводные

- **Атлет:** 27 лет, 186 см, 79–80 кг, опыт 1–2 года, коммерческий зал. **Не новичок** — техника и веса есть.
- **Жир:** ~17–20%. Низ живота + вздутие = **жир + ЖКТ + гипертонус таза/диафрагмы** (вздутие лечит [[health]], не спорт).
- **Приоритеты роста:** спина (ширина+толщина, №1) · средние/задние дельты · верх груди · верх спины. Ноги — держим, присед подтянуть.
- **Ограничения (профиль Здоровья):** гипертонус диафрагмы/таза + передний наклон таза.
  - Дыхание под нагрузкой: брэйсинг, **без экстрим-Вальсальвы** на максимумах.
  - Кор — **только анти-экстензия/анти-ротация** (планка, dead bug, Pallof). **❌ НЕТ скручиваний/подъёмов ног в висе** (флексия позвоночника + подвздошно-поясничная → усугубляют наклон таза). **НЕТ Кегелей.**
- **Кардио:** шаги 8–10k/день + 1–2 LISS; **велосипед — избегать в острые фазы таза.**

## 4. Прогрессия — двойная + авторегуляция

| Сигнал в логе | Решение |
|---|---|
| Добил **верх диапазона во ВСЕХ подходах** при RPE ≤8 | **+вес** (изоляция +1.25–2.5, база +2.5–5) |
| Попал в диапазон, RPE 9–10 | повтор веса, тянем повторы |
| Повторы **падают 2 трен подряд** | −5–10% или замена/разгрузка |
| RPE 10 + повторы упали + сон плохой | дилоад, не геройствуем |

Логируем каждый рабочий подход: **вес × повторы × RPE** → вход для прогрессии.

## 6. Питание (recomp)

- **Дефицит ~−10–15%** (≈ −300–400 ккал; поддержка ~при стабильных 79–80 кг).
- **Белок ~150–160 г/день** (1.9–2.0 г/кг).
- Белок каждый приём + овощи (профиль: мало овощей, много сахара/кофеина — чиним, связано со вздутием → [[health]]).
- Жиры не ниже ~0.8 г/кг (гормоны). Углеводы вокруг трен.

## 7. Кардио / расход

- **Шаги 8–10k/день** — главный рычаг дефицита.
- 1–2× LISS 20–30 мин (ходьба/эллипс/наклонная дорожка). **Велосипед — избегать в острые фазы таза.** HIIT не нужен.

## 8. Восстановление

- Сон 7–8 ч (хаотичный → ключевой рычаг recomp и тестостерона).
- Утренний валик/тазовая разминка (протокол Здоровья) — оставляем, синергия с наклоном таза.
- Дилоад по графику.
