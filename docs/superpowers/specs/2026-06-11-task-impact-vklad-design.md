# Дизайн: «Вклад в успех» — оценка задачи в % (Путь 1)

> Дата: 2026-06-11 · Фаза: мокап-дизайн (код позже) · Источник: брейншторм с владельцем.
> Связь: AI-PM реструктуризация (`2026-06-09-product-audit-and-restructure.md`), ZERO-AFK (`Alexandr/memory/zero-afk-architecture.md`), Форк 0 (Stage/Project AI-поля).

## Идея

Каждая задача получает **вклад в успех проекта** — число 0–100%. Важность задачи = этот вклад (ось «важность» Эйзенхауэра), срочность = из дедлайна. Так задачи различаются: срочные+важные / важные-не-срочные / срочные-не-важные / фон.

## Кто и когда оценивает (ZERO-AFK)

- **Интерактивный Claude в чате** при постановке/разборе задач пишет `Task.impact` через write-API. Тот же паттерн, что `Project.success_probability` и `ai_notes`.
- Приложение **само LLM не зовёт** — только показывает и сортирует. Нет фон-демона. Биллинг = подписка, не AFK-кредит.
- Задача, созданная в приложении без участия Claude → `impact = null`, токена нет, пока Claude не оценит.

## Модель данных

- Новое поле: **`Task.impact`** — `int | null`, диапазон 0–100.
- Срочность НЕ хранится — производная от `due_date` (есть/просрочен/сегодня/далеко).
- Старые поля целы: `priority` (кант), `project_id` (фон), `stage_id` (мишень-этап). Ничего не ломается.

## UI — токен (Путь 1, выбран)

- **Вид:** моно-пилюля **`80%`** в строке меты, рядом с «этап N». Число + знак `%` справа (без стрелки).
- **Цвет:** текст bone на slate-фоне — НЕ цвет-сигнал. Канал цвета строки занят (кант=приоритет, фон=проект, мишень=этап) — токен в него не лезет.
- **Правило показа:** виден если `impact ≥ ПОРОГ` (дефолт **30**, константа конфигурации) **И** задача привязана к проекту/цели (`stage_id` или `project_id` не null). Иначе скрыт — быт/инбокс/мелочь без токена, список не пухнет.
- **Деталь задачи:** `impact` показываем ВСЕГДА (даже ниже порога), там же место под обоснование Claude (опц.).

## Где появляется

- Таймлайн «Задачи»/«Сегодня» (T1).
- Строки видов «Списки».
- Деталь задачи (DETAIL) — всегда.

## Парк (будущая волна, НЕ сейчас)

- **Вид «Фокус»** — отдельный режим таба Задачи (переключатель Время/Фокус): задачи отсортированы по вкладу вниз, топ выделен. Дом для сортировки.
- **Матрица Эйзенхауэра** — доп-вид (4 квадранта срочность×важность). Стратегический обзор.
- Эти два не входят в текущий скоуп. Токен (Путь 1) самодостаточен.

## Отвергнуто

- **A (кольцо-бейдж %)** и **B (цвет-точка квадранта)** на строке — лезут третьим цветом в занятую цветовую систему строки. Конфликт.
- **Путь 2 (кант = AI-важность)** — теряется ручной `!1–3` приоритет, рискованно. Оставили кант за ручным приоритетом.
