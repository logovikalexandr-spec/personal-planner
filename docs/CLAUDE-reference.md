# CLAUDE Reference — триггеры и граф (lazy)

> Грузится по «полный контекст» / deep dive. Полная таблица триггеров + правила wikilink-графа.
> Базовые правила — в [[CLAUDE]]. Карта — в [[MEMORY]].

## Как я читаю сообщения

1. Парсю `[[X]]` в тексте пользователя.
2. Ищу файл `X.md` в vault (атомы в `сущности/*/`, `решения/`, `memory/`, `_MOC/`).
3. Проверяю триггеры (таблица ниже).
4. Читаю только нужное. Работаю.

## Правила графа

1. **Атомизация.** Новая сущность (экран/компонент/модель/решение) → отдельный файл.
2. **Wikilinks обязательны.** Каждый атом линкует связанные `[[имена]]` (вверх к экрану, вниз к модели/сервису).
3. **Один файл = один атом.** Не сливать.
4. **Путь к коду** в каждом атоме — чтобы от графа дойти до файла.
5. **Frontmatter `type:`** — для фильтра графа в Obsidian по типу узла.

## Маршруты «фича → код» (примеры обхода графа)

- Задачи: [[Сегодня]] → [[TaskItem]] / [[TaskComposer]] → [[Task]] → [[tasks-service]] → [[routes-tasks]]
- Проекты: [[Списки]] → [[ProjectTree]] → [[projectTree-lib]] → [[Project]] → [[projects-service]]
- Захват: бот → [[capture-handler]] → [[InboxItem]] → [[inbox-service]] → [[Inbox]]
- Авторизация: [[telegram-bot]] → [[allowlist]] → [[api-auth]]
