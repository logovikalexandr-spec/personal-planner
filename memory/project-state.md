## ⭐ ОТЛОЖЕНО: уход с Telegram → PWA (решено 2026-06-20, ждёт)
**Боль владельца (скрин реального TG):** (1) Telegram-шапка «Закрыть/⋯» режет верх экрана; (2) каждый заход через ТГ. Хочет «приложуху для себя».

**РАЗБИТО на 2 части (по срочности):**
- **A (косметика, можно СЕЙЧАС, фичи не трогает):** `manifest.json` + service worker + иконки + `safe-area-inset` под iOS статус-бар → standalone полный экран + иконка. Лечит обрезку сразу. Дёшево.
- **B (отвязка входа, ПОТОМ — когда фичи добьём):** сейчас auth = Telegram `initData`. Вне ТГ ломается → свой вход: бот один раз шлёт ссылку-ключ → токен в localStorage (+опц. Face ID/WebAuthn). Меняет как авторизуются ВСЕ запросы — завязано на бэк. Не зависит от готовности фич, потому в конец. Держать B на конец т.к. пока строим фичи заход через ТГ удобнее для отладки.

## ПЕРФ-ФИКС лагов (2026-06-03) — ЗАДЕПЛОЕНО
Жалоба «всё лагучее». Investigate-скилл + chrome perf-trace (4x throttle).
Root cause: app **React-render-bound** (0 React.memo во всём проекте) + **remount экрана на каждый tab-switch**
(Списки ремонтят dnd-kit ×14 useSortable). Layout/Paint дёшевы — узкое место = JS-рендер.
Фиксы (оба live, commits e3e8c91 + e53ae80, бандл index-Djg14S4d):
1. memo(TaskItem/ProjectTree.Row/DayTimeline) + useCallback (App/Today/TaskListBody) → внутри-экранное −37% JS.
2. **keep-alive табов** (App.tsx: mountedTabs + .screen-host[hidden]; экран монтируется раз, дальше show/hide) →
   warm tab-switch FunctionCall 328→73ms (−78%). Cold-load НЕ тяжелее (только Today монтируется на старте).
Полная цепочка baseline→now: 520→73ms JS (−86%) на той же серии переключений.
ПРОВАЛ (откатил): lazy-dnd через rAF — двойной рендер сделал хуже (108→337ms). Урок: не отклад rAF'ом mount dnd.
Остаётся: cold-load render-delay ~1с (мерил на dev — на проде меньше); ListView-колбэки не useCallback (бьют редко).
keep-alive побочка: hidden-экраны рефетчат на bump (больше сети, не лаг).
